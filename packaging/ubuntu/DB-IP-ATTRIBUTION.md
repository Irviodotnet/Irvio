# IP Geolocation by DB-IP

DB-IP Country Lite, September 2026, MMDB. Unmodified database.

- Publisher: DB-IP — https://db-ip.com/
- Source: https://db-ip.com/db/download/ip-to-country-lite
- Download: https://download.db-ip.com/free/dbip-country-lite-2026-09.mmdb.gz
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).
- License text: https://creativecommons.org/licenses/by/4.0/legalcode

Country Lite has reduced coverage/accuracy compared with the commercial database.
The UI also displays DB-IP attribution. The database is an installer asset, not
part of the Flutter bundle or the source repository. It is installed at
`/var/lib/irvio/geo/country.mmdb`. No automatic updater is installed.
